Four collections, one mental model

Ordered — items have a fixed position/index you can rely on

Mutable — can be changed in place after creation

Duplicates — can the same value appear more than once

TypeOrderedMutableDuplicatesUse
listYesYesYesgrowing sequence
tupleYesNoYesfixed record
dictYesYeskeys: nokey→value lookup
setNoYesNounique items, dedupe

Gotcha: a = [1,2,3]; b = a shares the same list — mutating one mutates both. Tuples avoid this entirely.
