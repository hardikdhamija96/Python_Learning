Variables are names, not boxes

C / Java mental model

A variable is a fixed box. Assignment overwrites what's inside it.

Python's model

A name is a label pointing at an object. Assignment re-points the label; it never overwrites the object.

a = [1, 2, 3]   b = a   a.append(4)   → b is [1, 2, 3, 4] too

Gotcha: two names can point to the same mutable object — change via one, the other sees it too.
