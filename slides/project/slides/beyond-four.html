Only 4 collections? Not quite.

list / tuple / dict / set cover ~95% of real analyst code — but a few others exist, worth recognizing (CONTEXT priority, not to master):

frozenset

An immutable set

str

Ordered, immutable sequence of characters — same family as list/tuple

bytes / bytearray

Raw binary data — rare in day-to-day work

pandas DataFrame / Series are built on top of these fundamentals, not alternatives to them.
