Is memory ever "absolutely free"?

Python is an interpreter, not a compiler — it runs line by line, top to bottom, as it reads. That's why a typo 50 lines down isn't caught until execution reaches it.

While running

Garbage collection frees an object the instant zero names point to it — ongoing, not a final step.

On exit

The OS reclaims everything the process used — blunt, total, regardless of references.

Real-world bite: holding unneeded references in a loop (e.g. an ever-growing list) blocks GC and climbs memory in long-running jobs.
